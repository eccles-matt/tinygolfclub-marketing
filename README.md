# The Tiny Golf Club: marketing site

The site for tinygolfclub.com. It is one static page, `index.html`, with everything inlined, so it can be hosted anywhere (Cloudflare Pages is the plan).

The page is one long playable par 5 that swerves down an all-grass page. The selling points sit on cards beside the fairway, and the green leads by cart path to the clubhouse cards: prices, what's included and the contact form.

Notes:
- Hector's Deli is a sample sponsor. Get their OK before the site goes public.
- The contact form is a mockup and sends nothing yet.
- Prices are drafts.

To preview locally, open `index.html` in a browser or run `python3 -m http.server`.
